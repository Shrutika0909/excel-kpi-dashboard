# 📊 Business KPI Dashboard using Excel

## 📌 Project Overview
This project demonstrates how Microsoft Excel can be used to track and analyse business performance through Key Performance Indicators (KPIs).

The dashboard uses fictional monthly business data to monitor leads, attendance, conversions and revenue.

## 🎯 Project Objectives
- Track monthly lead generation.
- Monitor attendance performance.
- Analyse conversion rates.
- Evaluate revenue trends.
- Present business performance through visual dashboards.

## 🛠️ Tools & Technologies
- Microsoft Excel
- Excel Formulas
- Data Analysis
- KPI Reporting
- Data Visualization

## 📈 Key Performance Indicators

| KPI | Calculation |
|---|---|
| Total Leads | Sum of monthly leads |
| Total Attendance | Sum of attended leads |
| Total Conversions | Sum of conversions |
| Attendance Rate | Attended / Leads × 100 |
| Conversion Rate | Converted / Attended × 100 |
| Revenue per Conversion | Revenue / Conversions |

## 📂 Project Files
- `Business_KPI_Dashboard.xlsx` – Contains the interactive dashboard, monthly dataset, formulas and charts.

## 💡 Key Learning Outcomes
- Understanding business performance metrics.
- Applying Excel formulas for data analysis.
- Creating KPI dashboards.
- Interpreting monthly performance trends.
- Presenting data for business decision-making.
